# Ownly Together: case study

Live: https://cercit.github.io/ownly-together/

How I took a group-ordering idea for Ownly's Chennai launch from problem to a working, tested prototype: research plan, personas, customer journey, market sizing, competitors, PRD, design, build, testing, roadmap and go-to-market.

- Live prototype: https://ownly-together.vercel.app/
- Code and documents: https://github.com/cercit/ownly.food

Light mode matches the prototype's Ownly pink; dark mode uses the colours of https://cercit.github.io/me/. This page is generated from `web/public/case-study/` in the ownly.food repo.

Concept prototype by Sameer Mittimani for the IIT Roorkee × Masai product management course. Not an official Rapido product.
